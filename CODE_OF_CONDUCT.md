# Code of Conduct

ClamUI follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct.html). We expect an inclusive, respectful, harassment-free community.

Report unacceptable behavior to [security@clamui.com](mailto:security@clamui.com). Reports are reviewed promptly and fairly, with reporter privacy respected.

Read the complete [Code of Conduct](https://clamui.com/docs/contributing/code-of-conduct/) for standards, scope, and enforcement guidelines.
